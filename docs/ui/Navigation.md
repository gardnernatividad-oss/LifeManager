# Navegación de LifeManager V1

La navegación autoritativa es:

```text
Inicio
Revisión
Planificación
  Tareas
  Pendientes
  Proyectos
Seguimiento
  Tareas
  Pendientes
  Proyectos
Reportes
  Tareas
  Pendientes
  Proyectos
Tablas
  Tareas
  Categorías
Configuración
```

V1 no muestra selector de Workspace: el contexto es siempre el Personal Workspace del usuario. Dashboard se denomina Inicio; Daily Workflow se reemplaza por Revisión; Tareas recurrentes no es un módulo y Categorías no pertenece a Configuración.

En móvil, los mismos destinos se presentan en una navegación colapsable. La jerarquía y los nombres no cambian entre tamaños de pantalla.
